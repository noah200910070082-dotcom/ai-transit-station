# 0 基礎 UI 流程

## 設計守門

本專案已接入 Impeccable：

```bash
npm run design:check
```

每次改 UI 後都要跑一次，用來檢查 AI 生成感、可讀性、對比、間距、觸控尺寸、卡片嵌套等問題。

## 進站

1. 使用者打開前端。
2. 首屏只能看到登入入口與登入窗口下方的好友邀請碼通道。
3. 右上角可以切換語言。
4. 登入頁在 1280x720 桌面視窗下不應需要下拉。

## 登入

1. 填帳號密碼。
2. 表單呼叫 `POST /api/user/login`。
3. 或填帳號、密碼、好友邀請碼，呼叫 `POST /api/user/register`。
4. 成功後再讀 `GET /api/user/self`。
5. 普通用戶進入自己的工作區。
6. 管理員進入管理員控制台。
7. 後端未連線時顯示明確提示，不假裝登入成功。

## 主頁

1. 顯示 `new-api` 角色、額度、請求次數與 API Key 數。
2. API Key 資料來自 `GET /api/token/`。
3. 管理員帳號池資料來自 `GET /api/channel/`。
4. 管理員用戶資料來自 `GET /api/user/`。
5. 智能調度、並發與限流沿用 `new-api` channel、group、priority 能力。
6. 管理員顯示全數據管理。

## 審計與運營

1. 看請求記錄。
2. 看扣費。
3. 看告警。
4. 看退款與發票。
